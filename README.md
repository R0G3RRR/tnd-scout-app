# TnD Scout para Android

O **TnD Scout** é o aplicativo Android da plataforma TnD Scout para acompanhamento de dados de diabetes integrados ao Nightscout. Ele reúne informações importantes em uma interface móvel e mantém o monitoramento disponível também por widgets e serviço em segundo plano.

## O que o aplicativo oferece

- leitura atual de glicose e tendência;
- histórico glicêmico e indicadores de tempo na faixa;
- informações de insulina ativa (IOB), carboidratos ativos (COB) e Loop, quando fornecidas pelo Nightscout;
- acompanhamento da idade do sensor e do conjunto de infusão;
- relatórios para consulta e acompanhamento;
- widgets Android e atualização em segundo plano;
- suporte a múltiplos pacientes vinculados à plataforma.

## Download

Baixe sempre a versão mais recente na página oficial de releases:

**[Baixar o TnD Scout para Android](https://github.com/R0G3RRR/tnd-scout-app/releases/latest)**

Este repositório é destinado somente à distribuição oficial do APK. O código-fonte do aplicativo é mantido separadamente em um repositório privado.

## Instalação

1. Abra a página de releases e baixe o arquivo `tnd-scout-vX.Y.Z.apk`.
2. No Android, abra o arquivo baixado.
3. Se solicitado, permita temporariamente a instalação de aplicativos provenientes do navegador ou gerenciador de arquivos utilizado.
4. Conclua a instalação e desative novamente essa permissão, caso não precise mais dela.

Ao atualizar, instale o novo APK sobre a versão existente para preservar os dados e configurações do aplicativo.

## Plataforma web

A plataforma web está disponível em [tndscout.vercel.app](https://tndscout.vercel.app/).

## Segurança e uso responsável

- Faça downloads somente por este repositório ou pelo atualizador integrado ao aplicativo.
- As credenciais do Nightscout são armazenadas de forma protegida no dispositivo.
- O TnD Scout auxilia na visualização de informações, mas não substitui avaliação, orientação ou decisão de um profissional de saúde.
